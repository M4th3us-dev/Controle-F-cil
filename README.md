# Controle Fácil — Interface Visual 2.0

Versão desktop do Controle Fácil com interface visual renovada.

## Recursos atuais

- Dashboard moderno
- Sidebar de navegação
- Cards de receitas, despesas, saldo e percentual gasto
- Gráfico de resumo financeiro
- Gráfico de despesas por categoria
- Últimas movimentações
- Cadastro de receitas
- Cadastro de despesas
- Edição de lançamentos
- Exclusão de lançamentos
- Cadastro de categorias
- Relatório consolidado
- SQLite
- Validação de valores
- Banco não é apagado na inicialização

## Instalação

```bash
pip install -r requirements.txt
```

## Execução

```bash
python main.py
```

### Importante

Mantenha seu `financeiro.db` atual para preservar os dados.
